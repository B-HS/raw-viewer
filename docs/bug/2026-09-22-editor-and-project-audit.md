# 레이어 편집 및 프로젝트 버그 점검

상태: 아래 확정 항목 수정 완료. 2026-09-22, dev.

## 점검 범위와 판정

프론트의 App 진입·파일 열기·탐색·파일 감시, 편집/히스토리/메타/내보내기 스토어, 도구 오버레이·좌표·합성, 키보드 처리와 Rust의 편집 저장·스캔·휴지통·내보내기 계약을 대조했습니다. Rust 전체 테스트도 실행했습니다. 정적 원인이 확정되거나 테스트로 재현된 문제만 아래 목록에 포함했습니다. 모든 플랫폼과 파일 조합에서 미발견 결함이 없다는 의미는 아닙니다.
