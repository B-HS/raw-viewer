# 독립 레이어 편집 작업공간

사진 보정 패널의 드로잉 섹션을 별도 레이어 편집 탭으로 분리했습니다. 사용자의 요청에 따라 서브에이전트 없이 직접 구현·검증했습니다.

구현 커밋: `b1be882` (`feat(editor): 독립 레이어 편집과 안정성 개선`). `origin/dev` 푸시 완료. prod·릴리스 태그 변경 없음.

## 동작

- 상단 탭으로 사진 보정/레이어 편집 전환. 편집 탭에는 좌측 도구막대, 상단 도구 옵션, 공용 캔버스, 우측 레이어/히스토리 패널을 배치했습니다.
- 이동·올가미·브러시·연필·지우개·채우기·복제·블러·직선·화살표·사각형·타원·텍스트와 새 손 도구를 실제 기존 편집 엔진에 연결했습니다. 도구별 크기·불투명도·채움, 선택 해제와 실행 취소/다시 실행을 제공합니다.
- 레이어 추가·선택·이름 변경·복제·표시·순서·삭제, 썸네일, 불투명도·블렌드·변형·레이어별 보정을 제공합니다. 원본 사진 보정은 사진 보정 탭에서 수행합니다.
- 단축키는 도구 툴팁에 표시합니다. Cmd/Ctrl+J 복제, Cmd/Ctrl+D 선택 해제, Delete/Backspace 레이어 삭제, 이동 도구의 방향키는 1px·Shift 10px 이동, 대괄호는 브러시 크기, Space/손 도구는 팬입니다.
- 사진·저장·히스토리·내보내기·파일 조작 등에서 확정된 기존 버그 21항목을 함께 수정했습니다. 상세는 [버그 목록](../bug/2026-09-22-editor-and-project-audit.md), 실행 근거와 제한은 [검증 기록](../quality-assurance/2026-09-22-editor-workspace.md)입니다.

## 구조와 범위

새 UI는 `src/widgets/editor/`, 공유 도구 정의는 `src/shared/constants/editor.ts`입니다. 기존 `components/panels/DrawerSection.tsx`는 제거하고 레이어 속성 UI를 `widgets/editor/editor-layers.tsx`로 이동했습니다. 기존 App·store·gl·ipc 구조 및 상대 import와 연결하는 점진적 배치이며 저장소 전체 FSD 전환은 하지 않았습니다. Rust 계약·생성 타입·외부 의존성은 변경하지 않았습니다.

이 작업은 기존 비파괴 드로잉/레이어 엔진을 독립 편집 작업공간으로 고도화한 것입니다. PSD 호환, 사진 픽셀 레이어 임포트, 마스크/조정 레이어, 스마트 오브젝트, 힐링 등 Photoshop 전체 기능을 구현한 것은 아닙니다. 기존 그림 레이어 사이 블렌드 의미를 유지합니다. 개발자 환경의 자동 Git 지침에 따라 dev에 검증된 변경을 기록합니다.
