## 준비된 릴리스 노트

제목: Raw Viewer 0.6.0

Separate photo development and layer editing workspaces, with a left-hand toolbox and a dedicated layer panel.

### New

- A dedicated Layer Editor tab with 14 tools, contextual tool options, and Layers/History panels.
- Layer duplication, renaming, thumbnails, positioning, opacity, blend modes, and per-layer adjustments.
- Tool shortcuts, layer nudging, selection clearing, brush sizing, and a Hand tool for canvas panning.

### Fixed

- Undo/redo now preserves complete strokes and multi-field edits.
- Painting and photo-sampling tools account for layer transformations.
- Saving retains pending edits after failures and includes changes made while a save is in flight.
- Image loading, folder scans, file watching, and RAW/JPEG switching reject stale responses.
- Export cleanup, DNG save ordering, metadata refresh, empty-screen dialogs, and keyboard handling were corrected.

### Scope

The editor uses non-destructive drawing layers. PSD compatibility, masks, and imported photo-pixel layers are not included. Layer editing requires a supported GPU renderer and a still image.

### Install

Download `Raw.Viewer_0.6.0_aarch64.dmg` and drag Raw Viewer into Applications. Requires macOS 13 or later on Apple silicon. Signing, notarization, checksums, and updater assets will be confirmed after the release build finishes; this note must not claim them before verification.
