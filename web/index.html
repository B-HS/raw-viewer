Features

Everything a shoot needs, nothing else

01

Fast RAW browsing

Staged decode (preview → edit quality → 100%), forward preloading of upcoming photos, near-zero idle CPU on large folders.

02

Non-destructive develop

White balance, tone curve, HSL, noise reduction, sharpening, lens correction, effects, crop — originals are never touched.

03

GPU pipeline

WebGL2 renderer with an experimental WebGPU backend, including compute-shader noise reduction.

04

Culling workflow

Star ratings, pick/reject flags, color labels, filters, RAW+JPEG pairing, grid view and slideshow.

05

Document scan

Flatten photographed documents — perspective and mesh dewarp with corner and edge handles, even for curled pages.

06

Drawing layers

Brushes, shapes, text, clone stamp and blur on layers — blend modes, per-layer adjustments, baked into exports.

07

Export

Batch JPEG/PNG/TIFF (8/16-bit) and DNG, edit presets, copy and paste settings between photos.

08

Localized

English, 한국어 and 日本語 — fully translated interface with remappable shortcuts.

Usage

Install once, fly on keys

Getting started

01
Download the DMG

Grab the latest release from GitHub — signed and notarized for Apple silicon.

02
Drag into Applications

Open the DMG and drop Raw Viewer into your Applications folder.

03
Open a folder of RAWs

Drag a file or folder onto the window. Updates arrive through the built-in updater.
